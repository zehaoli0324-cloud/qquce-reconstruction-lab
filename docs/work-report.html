项目级隔离安装、官方文件校验；实际启动 REA 与 Craft MCP。以本地计数器检验点击、Codex 调用与文件生成。

STEP 02

STEP 03

将证据变成独立产品

保留原题内容与来源，建立统一题库和计分引擎。实现作答、保存、漏题校验、报告与导出，使用独立品牌和界面。

产物：4 份可答题库，共 72 题
STEP 04

运行、核对、公开交付

桌面和手机浏览器检验关键流程；核对原题哈希与内容。公开源码、来源说明和测试记录，并通过 GitHub CI。

交付：源码、截图、运行命令

Craft 的完整生成验证对象是本地计数器样例；本项目题库页面也做了三宽捕获。当前测评引擎与应用由 Codex 编写，这两项工作分别记录。
